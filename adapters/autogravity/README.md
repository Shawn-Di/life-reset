# AutoGravity adapter

Import or paste `SKILL.md` into AutoGravity's supported custom instruction or Skill area. Connect the generated reminder to AutoGravity's own workflow or scheduling feature when available.

Use the user's existing AutoGravity identity and token. Reminders are enabled by default and can be changed with “关闭人生重启提醒” or “开启人生重启提醒”. If new-conversation automation is available, create or reuse a conversation titled `Life-reset`; otherwise deliver the generated reminder manually. This repository does not claim a private AutoGravity automation API.
