# Kimi adapter

Kimi Code native install:

```text
/plugins install https://github.com/Shawn-Di/life-reset
```

Kimi Code CLI portable install:

```bash
npx skills add Shawn-Di/life-reset -a kimi-code-cli
```

If neither is available, import or paste `skills/life-reset/SKILL.md` into Kimi's supported custom instruction or Skill area. Connect the generated reminder to one Kimi workflow or scheduling rule when available.

Use the user's existing Kimi identity and token. Reminders are enabled by default and can be changed with “关闭 Life-reset 提醒” or “开启 Life-reset 提醒”. Configure exactly one active automation named `Life-reset` with key `life-reset-v1`; list before creating, reuse or update one existing entry, and pause duplicates. Save one conversation ID and reuse that conversation while accessible. This repository does not claim a private Kimi automation API.
