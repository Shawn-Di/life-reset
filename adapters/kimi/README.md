# Kimi adapter

Kimi Code native install:

```text
/plugins install https://github.com/Shawn-Di/life-reset
```

Kimi Code CLI portable install:

```bash
npx skills add https://github.com/Shawn-Di/life-reset/tree/master/skills/life-reset -g -a kimi-code-cli --copy -y
```

If neither is available, import or paste `skills/life-reset/SKILL.md` into Kimi's supported custom instruction or Skill area. Connect the generated reminder to Kimi's own workflow or scheduling feature when available.

Use the user's existing Kimi identity and token. Reminders are enabled by default and can be changed with “关闭人生重启提醒” or “开启人生重启提醒”. If new-conversation automation is available, create or reuse a conversation titled `Life-reset`; otherwise deliver the generated reminder manually. This repository does not claim a private Kimi automation API.
