# WorkBuddy adapter

Import or paste `SKILL.md` into WorkBuddy's supported custom instruction or Skill area. Connect the generated reminder to WorkBuddy's own workflow or scheduling feature when available.

Use the user's existing WorkBuddy identity and token. Reminders are enabled by default and can be changed with “关闭人生重启提醒” or “开启人生重启提醒”. If new-conversation automation is available, create or reuse a conversation titled `Life-reset`; otherwise deliver the generated reminder manually. This repository does not claim a private WorkBuddy automation API.
