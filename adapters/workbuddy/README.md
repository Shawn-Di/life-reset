# WorkBuddy adapter

When the WorkBuddy `gh skill` preview is available, install with one command:

```bash
gh skill install Shawn-Di/life-reset skills/life-reset --dir .workbuddy/skills
```

Otherwise, upload the repository release ZIP in WorkBuddy's Skill Marketplace, or import `skills/life-reset/SKILL.md` into its supported custom instruction or Skill area. Connect the generated reminder to WorkBuddy's own workflow or scheduling feature when available.

Use the user's existing WorkBuddy identity and token. Reminders are enabled by default and can be changed with “关闭人生重启提醒” or “开启人生重启提醒”. If new-conversation automation is available, create or reuse a conversation titled `Life-reset`; otherwise deliver the generated reminder manually. This repository does not claim a private WorkBuddy automation API.
