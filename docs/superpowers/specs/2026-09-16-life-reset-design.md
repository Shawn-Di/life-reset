# 人生重启（life-reset）设计规格

## 1. 目标

构建一个 GitHub 开源、可被多个 AI 工具安装或复制使用的提醒 Skill。第一版只围绕 Dan Koe 的文章《How to fix your entire life in 1 day》，通过自动化在预定时间创建一个新对话，把一次提醒作为该对话的初始状态呈现给用户。

产品显示名为“人生重启”，包名为 `life-reset`。

## 2. 范围

### 第一版包含

- 一个平台无关的提醒内容格式。
- 一份基于目标文章的中文提醒内容。
- 用户可配置的提醒时间窗口、频率和时区字段。
- 新对话提醒协议：自动化创建新对话，并以提醒消息作为首条消息。
- Codex 适配说明，以及其他平台的通用适配契约。
- 内容来源链接、作者信息和简短摘要。

### 第一版不包含

- 抓取 X 或 newsletter 的实时内容。
- 收录或重新发布文章全文。
- 账号登录、云端数据库和统一托管服务。
- 依赖平台私有 API 的强制弹窗、阻断或确认机制。
- 多作者、多主题内容推荐界面。

## 3. 核心架构

项目分为三层：

1. **Content Pack**：保存提醒文案、来源链接、主题和行动问题。
2. **Reminder Contract**：规定提醒状态、配置字段和新对话消息格式。
3. **Platform Adapter**：把统一提醒契约映射到目标 AI 工具的 Skill、工作流或自动化能力。

核心层不依赖任何具体平台。平台只负责两件事：触发时间到达，以及创建一个新的对话并注入提醒消息。

## 5. 内容协议

`life-reset.json` 保存以下信息：

- `id`：稳定的内容 ID。
- `title`：提醒标题。
- `author`：作者。
- `sourceUrl`：原文链接。
- `sourcePublishedAt`：原文发布日期。
- `summary`：不超过几段的中文摘要。
- `prompt`：给用户思考的问题。
- `action`：当天可执行的最小行动。
- `copyrightNote`：说明仓库只保存摘要和链接，不保存全文。

提醒文案由这些字段拼接生成，不在各平台适配器中重复维护。

## 6. 提醒状态与数据流

```text
调度器到达时间
        ↓
读取用户配置
        ↓
加载 life-reset 内容包
        ↓
生成 reminder message
        ↓
创建新的 AI 对话
        ↓
首条消息标记为 pending reminder
```

第一版不要求用户点击“已读”。“新对话已创建”就是提醒成功；如果平台返回失败，适配器记录错误并允许下一次调度重试。

建议内部状态值：

- `scheduled`：等待调度。
- `created`：新对话已创建。
- `failed`：创建失败，保留错误信息。

## 7. 提醒配置

配置保持平台无关：

- `enabled`：是否启用。
- `timezone`：用户时区。
- `frequency`：例如每周 2 次。
- `timeWindow`：允许创建新对话的时间范围。
- `randomize`：是否在时间窗口内随机选择时间。

具体平台如果不支持随机调度，可以退化为固定时间；适配器必须在文档中说明限制。

## 8. 平台适配边界

每个平台适配器只包含：

- 安装位置和安装方式。
- 对应的工作流 / 任务配置示例。
- 创建新对话时需要注入的首条消息模板。
- 平台能力限制。

Codex 作为第一适配目标，使用 Skill 指令和自动化新建对话能力。其他平台先提供契约和手动配置模板，不假设其拥有相同的自动化 API。

## 9. 错误处理

- 内容文件缺失或格式错误：启动时失败，并指出文件路径和字段。
- 时间配置无法解析：拒绝本次调度，不创建空提醒对话。
- 新对话创建失败：记录 `failed` 状态和平台错误，不重复创建同一轮提醒。
- 平台不支持新对话自动化：输出可复制的提醒消息和人工配置方式。
- 网络不可用：第一版不抓取远程内容，已有内容仍可正常生成。

## 10. 测试策略

- JSON Schema 校验内容包和提醒配置。
- 测试提醒消息包含标题、行动、思考问题和来源链接。
- 测试缺失字段、非法时间窗口和未知状态会得到明确错误。
- 对 Codex 适配器做一次端到端手动验证：触发自动化，确认生成独立新对话且首条消息为提醒。
- 不测试第三方平台未提供的私有 API 行为。

## 11. 后续扩展

在第一版稳定后再考虑：

- 加入文章中的多个阶段提醒，例如早晨反思、白天打断自动驾驶、晚间总结。
- 增加更多 Dan Koe 个人成长内容，由用户选择启用。
- 增加内容版本和已提醒记录，避免短期重复。
- 为不同平台提供真正可导入的自动化文件。
- 增加用户自己的目标、反愿景和行动记录。
